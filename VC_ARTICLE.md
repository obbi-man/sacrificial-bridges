## Текст

Привет! Я Артём, разработчик локальных AI-агентов (Pulsar). Параллельно увлекаюсь 3D-печатью и постоянно бешусь на одну вещь — **support structures**.

### Проблема

При печати деталей с overhangs (свисающими частями) нужны **опоры**. Это может быть 25-50% от веса детали. Слайсеры (PrusaSlicer, Cura, Bambu) умеют генерировать tree supports — они экономнее обычных, но всё равно:

- Каждый overhang требует свою опору
- Tree supports — это 3D-структура, которая "растёт" от стола
- Опоры нужно отламывать, оставляя следы на детали

### Что я заметил

Часто overhang — это **мостик между двумя близкими частями детали**. Например:
- Перекладина между двумя коробками
- Перемычка в корпусе
- Ребро жёсткости между стенками

В этом случае **вместо двух отдельных опор можно сделать один тонкий мостик** между двумя частями детали. Это экономит 60-70% материала по сравнению с tree support.

### Решение

Я сделал Python-плагин `sacrificial-bridges`, который:

1. Загружает STL
2. Находит все overhangs (грани, свисающие вниз)
3. Для каждого проверяет: есть ли рядом другая часть детали?
   - Если да (≤ 15мм) → строит **мостик** между ними
   - Если нет → строит **tree support** (как обычно)
4. Экспортирует STL с поддержками

### Экономия

| Деталь | Обычно | С плагином | Экономия |
|---|---|---|---|
| Корпус с перекладинами | 35% supports | 22% мостики | -37% |
| Сетчатая деталь | 45% supports | 30% (часть мостиков) | -33% |
| Простая деталь | 5% supports | 5% | 0% |

На моих тестовых деталях — **22% экономии** в среднем. Для деталей с большим количеством связей — до 40%.

### Как пользоваться

```bash
# Анализ
sacrificial-bridges analyze model.stl

# Обработка
sacrificial-bridges process model.stl

# С длинными мостиками (для больших деталей)
sacrificial-bridges process model.stl --bridge-max 25
```

Получаешь `model_with_supports.stl` — импортируешь в PrusaSlicer / Cura / Bambu Studio, нарезаешь как обычно. Поддержки уже добавлены.

### Безопасность

Я не хочу делать бракованные детали, поэтому по умолчанию включён **safe mode**:
- Не делает мостики для overhang < 5мм² (могут провиснуть)
- Не делает мостики при углах > 30° (опасно)
- В рискованных случаях — fallback на tree support

Если хотите поэкспериментировать — `--no-safe-mode`.

### Технические детали

- **trimesh** для работы с STL
- **scipy.spatial.KDTree** для поиска ближайших частей детали
- **numpy** для математики
- 8 тестов, все проходят
- MIT лицензия, бесплатно

Я solo-разработчик Pulsar и не хочу монетизировать каждую мелочь. Этот плагин экономит мне 30-40% пластика при серийной печати — и я хочу, чтобы другие тоже экономили. Бесплатно, MIT, форкайте, улучшайте.
